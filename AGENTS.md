# AGENTS.md — инструкции для AI-агента в проекте S4 Template HTML

HTML-шаблон на базе кодо-центричной системы **С4** (в коде и именах файлов — **S4**). Вся вёрстка — только классами С4; ручной CSS не пишется.

## Что прочитать перед началом

Перед любыми правками `.html` / `.css` изучи документацию (все файлы лежат в папке `s4/`):

- [s4/S4.md](./s4/S4.md) — архитектура, формулы классов, пресеты, API `S4()`.
- [s4/AGENT.md](./s4/AGENT.md) — **контракт генерации**: формулы, правила, few-shot, запреты. Основной источник при вёрстке.
- [s4/LAYOUT.md](./s4/LAYOUT.md) — краткий гайд вёрстки: адаптив без брейкпоинтов, токены, паттерны (cookbook).
- [s4/index.md](./s4/index.md) — словарь базовых классов. Проверяй существование класса здесь до вставки в `class=""`.
- [s4/REFERENCE-UTILITIES.md](./s4/REFERENCE-UTILITIES.md) — полный список утилитарных классов.
- [s4/REFERENCE-ELEMENTS.md](./s4/REFERENCE-ELEMENTS.md) — все элементы С4.

## Правила вёрстки

- **Приоритет документации**: инструкции из `s4/S4.md` и `s4/AGENT.md` — наивысший приоритет. Выбор классов, отступов, размеров, имён свойств — только по ним.
- **Только логические свойства**: `margin-block`, `padding-inline`, `inline-size`, `inset-*` и т.п. Физические (`margin-top`, `width`, `right`) — запрещены.
- **Без инлайн-стилей**, произвольных `px`/`rem` и сбросов, если не предписано в S4.md/AGENT.md.
- **Один класс = одно свойство.** Формулы классов (единая / адаптивная / переменная) и запреты — строго по [s4/AGENT.md](./s4/AGENT.md).
- **Перед вставкой класса** сверься со словарём [s4/index.md](./s4/index.md), чтобы не допустить галлюцинаций.

## Подключение S4

S4 уже подключён в шаблоне: в `<head>` загружен `s4/js/s4.min.js` и вызван `S4()`. При добавлении новых страниц подключай так же. Не редактируй файлы в `s4/` — это неизменяемый дистрибутив системы.
