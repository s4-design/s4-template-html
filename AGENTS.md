# AGENTS.md — инструкции для AI-агента в проекте S4 Template HTML

## Правило - Знакомство с "Системой 4"
Перед началом работы и любыми изменениями `.html` или `.css` — сначала прочитать [s4/S4.md](./s4/S4.md), где содержится архитектура, формулы классов, пресеты и API.

## Правило - Приоритет S4.md
Инструкции из `s4/S4.md` имеют наивысший приоритет при вёрстке. Все решения по выбору классов, отступам, размерам, именованию свойств — только в соответствии с S4.md. Не использовать инлайн-стили, физические свойства, произвольные `px`/`rem` и сбросы, если S4.md предписывает иное.
